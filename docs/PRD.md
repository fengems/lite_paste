# Lite Paste 产品需求文档

## 1. 产品背景

macOS 用户常用剪贴板管理工具来保存复制历史、快速检索内容、重复粘贴高频片段，并处理文本、图片、文件等多种剪贴板类型。现有工具各有优势，但也存在明显取舍：

- Maccy 小巧、免费、原生且稳定，但界面表现相对朴素。
- Paste 交互和视觉体验优秀，功能完整，但订阅价格较高。
- EcoPaste 免费且界面现代，功能覆盖较广，但基于 Tauri 构建，运行时更重，并且当前维护活跃度不足。

Lite Paste 的目标是在 macOS 上提供一个原生、漂亮、轻量且功能完整的剪贴板管理工具，既保留 Maccy 的低资源占用和键盘效率，又吸收 Paste 的高级视觉体验和 EcoPaste 的功能组织思路。

## 2. 产品目标

Lite Paste v1 面向重度 macOS 用户、开发者、设计师、内容创作者和日常办公用户，提供可靠、快速、隐私友好的剪贴板历史管理体验。

核心目标：

- 原生体验：使用 SwiftUI + AppKit 构建，避免 WebView 运行时。
- 美观易用：提供接近 Paste 的玻璃感浮窗、卡片预览和现代 macOS 视觉风格。
- 低内存占用：按需加载历史内容，大型图片和富媒体使用外部文件存储。
- 功能完整：覆盖常用剪贴板管理、搜索、收藏、置顶、自动粘贴、隐私过滤和备份恢复。
- 隐私优先：默认过滤敏感来源和临时剪贴板类型，提供私密模式和应用黑名单。

## 3. 产品定位

Lite Paste 是一款原生 macOS 剪贴板管理器，定位为 Paste 的轻量替代品，而不是简单的 Maccy 换皮或 EcoPaste 移植。

产品关键词：

- 原生
- 美观
- 轻量
- 快速
- 隐私友好
- 功能完整

v1 不做跨平台，不做 iCloud 同步，不复用 Maccy 或 EcoPaste 的源码。项目仅参考二者的公开产品思路、架构形态和功能边界，核心实现重新编写。

## 4. 竞品参考

### 4.1 Maccy

可参考点：

- 原生 macOS 菜单栏应用形态。
- 基于 NSPasteboard 的轻量剪贴板监听。
- 全局快捷键唤起剪贴板面板。
- 键盘优先的搜索、选择、粘贴流程。
- 本地存储和低资源占用策略。

不直接沿用点：

- 不以纯列表为唯一主界面。
- 不直接复制 Maccy 代码。
- 视觉层需要更接近现代商业级 macOS 工具。

### 4.2 Paste

可参考点：

- 视觉精致的浮窗体验。
- 卡片式历史内容浏览。
- 对图片、文件、链接、富文本等内容的高级预览。
- 顺滑的搜索、筛选和粘贴体验。

不直接沿用点：

- 不复制 Paste 的品牌、界面细节或商业模式。
- v1 暂不做云同步和团队协作。

### 4.3 EcoPaste

可参考点：

- 内容分组：全部、文本、图片、文件、收藏等。
- 设置项组织：剪贴板行为、窗口行为、历史数量、快捷键、备份等。
- 笔记、收藏、删除确认、纯文本粘贴等高频功能。

不直接沿用点：

- 不采用 Tauri 作为主技术路线。
- 不复用现有插件代码。
- 不做跨平台兼容层。

## 5. v1 范围

Lite Paste v1 目标是达到 Paste 级完整体验的本地单机版本，而不是只做最小可用工具。

v1 包含：

- 菜单栏常驻应用。
- 全局快捷键唤起主面板。
- 剪贴板历史自动捕获。
- 文本、富文本、HTML、图片、文件、URL、邮箱、颜色等常见类型识别。
- 卡片模式和列表模式双视图。
- 搜索、分类筛选、收藏、置顶、删除、清空。
- 自动粘贴到上一个活跃应用。
- 粘贴为纯文本。
- 条目备注。
- 本地数据库存储。
- 大型内容外部文件存储。
- 应用黑名单和敏感内容过滤。
- 本地导入导出备份。
- 基础设置页。

v1 不包含：

- iCloud 同步。
- 账号系统。
- 团队共享。
- 跨平台版本。
- App Store 沙盒优先适配。
- 复杂规则自动化。
- OCR 搜索作为必选能力。图片 OCR 可作为后续增强项预留。

## 6. 技术路线

### 6.1 平台

- 最低支持版本：macOS 15+。
- 开发语言：Swift。
- UI 框架：SwiftUI + AppKit。
- 应用形态：菜单栏常驻应用，主界面使用浮动 NSPanel。

### 6.2 核心技术选择

- 使用 NSStatusItem 实现菜单栏入口。
- 使用 NSPanel 承载主剪贴板面板。
- 使用 SwiftUI 构建主要界面。
- 使用 AppKit 桥接系统能力，包括 NSPasteboard、全局快捷键、Accessibility 自动粘贴、窗口定位和系统材质。
- 使用 SwiftData + SQLite 存储历史元数据。
- 对图片、富文本、大型二进制内容使用 Application Support 下的外部文件存储。
- 设置项使用 UserDefaults 或轻量配置模型保存。

### 6.3 构建要求

项目需要完整 Xcode 环境进行构建和签名验证。当前如仅安装 Command Line Tools，后续需要安装完整 Xcode 或切换 `xcode-select` 到完整 Xcode 路径。

## 7. 核心功能需求

### 7.1 剪贴板捕获

系统应持续监听通用剪贴板变化，并在检测到新内容时创建历史条目。

需求：

- 支持文本、富文本、HTML、图片、文件、URL、邮箱、颜色等类型。
- 支持保留原始 pasteboard type，便于后续尽量按原格式恢复。
- 对完全相同内容进行去重。
- 重复复制同一内容时更新复制次数和最后复制时间。
- 可配置重复复制时是否移动到历史顶部。
- 记录来源应用名称和 bundle id。
- 忽略由 Lite Paste 自己写入剪贴板造成的循环记录。
- 忽略系统临时、内部、无展示价值或隐私风险高的 pasteboard type。

### 7.2 历史浏览

主面板提供两种视图模式。

卡片模式：

- 横向或分组卡片布局。
- 适合预览图片、文件、链接和富文本。
- 强调视觉层次、macOS 玻璃感和快速浏览。

列表模式：

- 高密度垂直列表。
- 适合键盘流和大量历史记录检索。
- 支持快速选择、上下移动和回车粘贴。

通用要求：

- 用户可在设置或面板中切换默认模式。
- 两种模式共享同一套历史数据、搜索条件和操作能力。
- 面板应支持深色和浅色模式。
- 面板应在多显示器和全屏空间下正确定位。

### 7.3 搜索与筛选

需求：

- 支持按文本内容、文件名、URL、备注、来源应用搜索。
- 支持按类型筛选：全部、文本、图片、文件、收藏、置顶。
- 搜索应实时响应，适合千级历史记录。
- 搜索框支持自动聚焦配置。
- 可配置打开面板时是否清空上次搜索。

### 7.4 条目操作

每个历史条目应支持以下操作：

- 复制回剪贴板。
- 自动粘贴到上一个活跃应用。
- 粘贴为纯文本。
- 收藏或取消收藏。
- 置顶或取消置顶。
- 添加或编辑备注。
- 删除单条记录。
- 清空未置顶记录。
- 清空全部记录，需二次确认。

针对特定类型：

- URL 可打开浏览器。
- 邮箱可打开邮件客户端。
- 文件可在 Finder 中显示。
- 图片可导出或复制为图片。

### 7.5 自动粘贴

当用户选择条目执行粘贴时，系统应先恢复剪贴板内容，然后通过 Accessibility 权限模拟系统粘贴快捷键。

需求：

- 首次使用自动粘贴时提示用户授予 Accessibility 权限。
- 未授权时降级为仅复制到剪贴板，并提示用户。
- 支持普通粘贴和纯文本粘贴。
- 自动粘贴完成后可按配置恢复或保留当前剪贴板内容。

### 7.6 收藏与置顶

需求：

- 收藏条目在收藏筛选中展示。
- 置顶条目在普通历史列表顶部展示。
- 置顶条目不受普通历史清理策略影响。
- 可为置顶条目分配快捷键，用于快速粘贴。

### 7.7 备注

需求：

- 用户可为任意历史条目添加备注。
- 备注参与搜索。
- 备注编辑应轻量，不进入复杂知识库或标签系统。

### 7.8 导入导出

v1 支持本地备份，不做云同步。

需求：

- 导出历史数据库、设置和外部 blob 文件。
- 导入备份时校验文件完整性。
- 导入可选择覆盖当前数据或合并数据。
- 合并时通过内容 hash 避免重复导入。

## 8. 隐私与安全

Lite Paste 默认采用强隐私策略。

默认行为：

- 忽略密码管理器、私密窗口或系统标记的敏感剪贴板内容。
- 忽略临时和内部 pasteboard type。
- 支持应用黑名单，来自黑名单应用的内容不进入历史。
- 提供私密模式，开启后暂停记录新剪贴板内容。
- 清空历史需要二次确认。
- 本地数据默认只保存在用户设备上。

设置项：

- 应用黑名单。
- 忽略 pasteboard type 列表。
- 最大历史数量。
- 历史保留天数。
- 是否记录图片。
- 是否记录文件路径。
- 是否默认粘贴纯文本。
- 是否启动时进入私密模式。

## 9. 数据模型

### 9.1 ClipboardItem

用于描述一条剪贴板历史记录。

字段：

- id：唯一标识。
- kind：内容类型，如 text、richText、html、image、files、url、email、color、unknown。
- title：面板中展示的主标题。
- searchText：用于搜索的归一化文本。
- note：用户备注。
- sourceAppBundleId：来源应用 bundle id。
- sourceAppName：来源应用名称。
- createdAt：首次复制时间。
- lastCopiedAt：最后复制时间。
- lastUsedAt：最后使用时间。
- copyCount：复制次数。
- isFavorite：是否收藏。
- isPinned：是否置顶。
- pinShortcut：置顶快捷键。
- contentHash：用于去重和导入合并。

### 9.2 ClipboardContent

用于保存一条历史记录包含的实际剪贴板内容。

字段：

- id：唯一标识。
- itemId：所属 ClipboardItem。
- pasteboardType：原始 pasteboard type。
- storageMode：inline 或 external。
- inlineData：小型内容的内联数据。
- externalFileURL：大型内容的外部文件路径。
- byteSize：内容大小。
- displayOrder：恢复 pasteboard 时的顺序。

### 9.3 AppSettings

用于保存用户设置。

字段：

- hotkey：主面板全局快捷键。
- viewMode：默认视图，card 或 list。
- maxHistoryCount：最大历史数量。
- retentionDays：历史保留天数。
- enabledTypes：允许记录的内容类型。
- ignoredPasteboardTypes：忽略的 pasteboard type。
- ignoredApps：应用黑名单。
- autoPasteMode：自动粘贴模式。
- pastePlainByDefault：是否默认纯文本粘贴。
- privacyMode：是否开启私密模式。
- launchAtLogin：是否开机启动。

## 10. 核心服务

### 10.1 ClipboardMonitor

职责：

- 监听 NSPasteboard 变化。
- 读取当前剪贴板内容。
- 调用 PrivacyFilter 过滤敏感内容。
- 生成 ClipboardItem 和 ClipboardContent。
- 调用 HistoryStore 保存历史。

### 10.2 HistoryStore

职责：

- 管理 SwiftData 数据读写。
- 执行历史查询、搜索和筛选。
- 根据 contentHash 去重。
- 执行保留策略和清理策略。
- 管理收藏、置顶、备注和删除操作。

### 10.3 PasteboardWriter

职责：

- 将历史内容恢复到 NSPasteboard。
- 支持原格式恢复。
- 支持纯文本恢复。
- 标记由 Lite Paste 写入的剪贴板内容，避免被 ClipboardMonitor 再次记录。

### 10.4 PanelCoordinator

职责：

- 管理 NSPanel 生命周期。
- 控制面板显示、隐藏、定位和焦点。
- 处理多显示器、菜单栏位置和全屏空间。

### 10.5 GlobalHotkeyController

职责：

- 注册和注销全局快捷键。
- 处理主面板唤起。
- 处理置顶条目快速粘贴。

### 10.6 PrivacyFilter

职责：

- 判断内容是否应该记录。
- 维护默认敏感 pasteboard type 列表。
- 应用用户配置的黑名单和忽略规则。
- 处理私密模式。

### 10.7 ImportExportService

职责：

- 导出本地备份包。
- 导入备份包。
- 校验备份完整性。
- 支持覆盖和合并导入。

## 11. 设置需求

设置页至少包含以下分区：

- 通用：开机启动、菜单栏显示、默认视图、面板位置。
- 剪贴板：记录类型、自动粘贴、纯文本粘贴、重复内容处理。
- 快捷键：打开面板、快速粘贴置顶条目。
- 历史：最大数量、保留天数、清空历史。
- 隐私：私密模式、应用黑名单、忽略类型。
- 备份：导出、导入。
- 关于：版本、许可证、项目说明。

## 12. 验收标准

v1 完成时应满足：

- 应用可作为菜单栏工具启动和退出。
- 全局快捷键可稳定打开和关闭剪贴板面板。
- 文本、富文本、图片、文件、URL 等常见内容可被记录和恢复。
- 搜索和筛选在千级历史记录下仍保持流畅。
- 卡片模式和列表模式均可完整执行复制、粘贴、收藏、置顶、删除。
- 自动粘贴在授权后可粘贴到上一个活跃应用。
- 未授权 Accessibility 时有明确降级行为。
- 隐私过滤默认启用，并能忽略黑名单应用。
- 导出和导入可以完成一次完整数据往返。
- 深色和浅色模式下界面均无明显视觉问题。
- 常规使用下内存占用保持在轻量水平，避免因大量图片一次性载入导致明显膨胀。

## 15. 开发基线

首个开发切片以“可运行的原生菜单栏剪贴板工具”为目标，先建立稳定工程结构和核心数据流，再逐步补齐 Paste 级体验。

工程默认值：

- App 名称：Lite Paste。
- Bundle Identifier：`com.fengems.LitePaste`。
- 初始版本号：`0.1.0 (1)`。
- 本地开发入口：Swift Package，可通过 `swift run LitePaste` 启动基础原生应用。
- 后续正式分发入口：完整 Xcode app target，用于签名、打包和权限声明。
- 当前 Command Line Tools 环境下先使用持久化中立的核心模型；接入完整 Xcode app target 后再启用 SwiftData 持久化模型。
- 正式 App target 的 Info.plist、entitlements 和接入说明分别维护在 `Config/LitePaste/` 与 `docs/MACOS_APP_TARGET.md`。

首个切片包含：

- 菜单栏入口。
- 浮动剪贴板面板。
- 卡片模式和列表模式的基础 UI。
- 文本剪贴板监听、去重、搜索、收藏、置顶、删除。
- 基础隐私过滤。
- SwiftData 模型和核心服务雏形。
- 单元测试覆盖去重、过滤和搜索等核心逻辑。
