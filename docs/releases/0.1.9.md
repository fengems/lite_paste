# Lite Paste 0.1.9

Lite Paste 0.1.9 adds configurable formatting for spreadsheet plain-text paste output.

## Highlights

- Added the **Format Table Plain Text** setting.
- Tab-separated table fields are trimmed and rejoined with a configurable separator.
- Empty cells and blank rows are skipped.
- Spaces inside a field are preserved.
- Added preset field wrappers: none, double quotes, single quotes, Chinese quotes, square brackets, and curly braces.
- Original tab-separated history records remain unchanged.
- Formatting applies only to plain-text paste output; copy-only plain text remains unchanged.

## Build

Build the normal local app:

```bash
Scripts/build_app_bundle.sh --open
```

Build the isolated development-channel app:

```bash
LITEPASTE_FLAVOR=dev Scripts/build_app_bundle.sh --open
```

## Verification

Verify the source checkout and core behavior:

```bash
Scripts/verify_metadata.sh
swift build
swift run LitePasteCoreChecks
git diff --check
```

Verify the local release package:

```bash
Scripts/verify_release.sh
```

## Notes
