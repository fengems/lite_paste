# Lite Paste 0.1.7

Lite Paste 0.1.7 makes plain-text copy and paste faster and more consistent, including direct paste flows between other apps.

## Highlights

- The clipboard panel toolbar now has quick toggles for copying and pasting as plain text.
- Ordinary copy and paste entry points, including primary actions, Return, ⌘C, quick buttons, and menus, honor the default plain-text settings.
- A new **Auto-Sanitize System Clipboard** setting rewrites rich system clipboard content after other apps copy rich text or HTML when either plain-text default is enabled.
- History capture still follows the existing rich-text retention rules, so supported original formats can remain available for later restoration.
- Files, images, and rich content without a usable plain-text representation are not rewritten.

## Build

Build the normal local app:

```bash
Scripts/build_app_bundle.sh --open
```

Build the isolated development-channel app:

```bash
LITEPASTE_FLAVOR=dev Scripts/build_app_bundle.sh --open
```

## Verification

Verify the source checkout and core behavior:

```bash
Scripts/verify_metadata.sh
swift build
swift run LitePasteCoreChecks
git diff --check
```

Verify the local release package:

```bash
Scripts/verify_release.sh
```

## Notes

- macOS does not provide a reliable pre-copy interception API for ordinary apps. Auto-sanitizing happens after Lite Paste observes the external clipboard change.
- Public distribution remains source-first because the project does not currently have Apple Developer Program credentials for Developer ID signing and Apple notarization.
