# Lite Paste 0.1.3

Lite Paste 0.1.3 adds a local development build channel so active development can run beside the normal app without sharing app identity, settings, or clipboard history.

## Highlights

- Added `Lite Paste Dev` as an isolated local build channel.
- Dev builds use bundle id `com.fengems.LitePaste.dev`.
- Dev builds store data under `~/Library/Application Support/LitePaste-Dev/`.
- Dev builds default to `Command + Option + Shift + V`, while the normal app keeps `Command + Shift + V`.
- Packaging scripts now emit separate `LitePasteDev-*` artifacts for Dev builds.

## Build

Build the normal local app:

```bash
Scripts/build_app_bundle.sh --open
```

Build the isolated development-channel app:

```bash
LITEPASTE_FLAVOR=dev Scripts/build_app_bundle.sh --open
```

## Verification

Verify the source checkout and core behavior:

```bash
Scripts/verify_metadata.sh
swift build
swift run LitePasteCoreChecks
git diff --check
```

Verify the normal local package:

```bash
Scripts/package_release.sh
Scripts/verify_dmg_contents.sh
```

Verify the Dev local package:

```bash
LITEPASTE_FLAVOR=dev Scripts/package_release.sh
LITEPASTE_FLAVOR=dev Scripts/verify_dmg_contents.sh
```

## Notes

- This release remains source-first for public distribution because the project does not currently have Apple Developer Program credentials for Developer ID signing and notarization.
- Dev and normal builds are intended to coexist locally; public distribution should still use the normal app identity.
