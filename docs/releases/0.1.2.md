# Lite Paste 0.1.2

Lite Paste 0.1.2 is the first public source release. It is published without a notarized macOS installer because the project does not currently have an Apple Developer Program membership for Developer ID signing and Apple notarization.

## Highlights

- Native macOS menu-bar clipboard manager for macOS 15+.
- Card and list clipboard panels with search, filters, favorites, pinned items, notes, and clear/delete actions.
- Keyboard-first workflow with `Command + Shift + V`, `Command + F`, arrow navigation, Return to paste, and `Command + 1` through `Command + 6` quick selection.
- Local-first storage with SQLite history and external blob files for large media.
- Privacy controls for paused monitoring, ignored apps, and sensitive pasteboard types.
- Local backup import/export and iCloud Drive backup that keeps the latest backup only.
- First-run permission guide explaining Accessibility permission and local privacy behavior.

## Install

Download the source archive from this release page, or clone the repository, then build the app locally:

```bash
Scripts/build_app_bundle.sh --open
```

The generated local app bundle is useful for developers and testers. It is not a Developer ID signed or notarized public installer.

## Verification

Verify the source checkout and core behavior:

```bash
Scripts/verify_metadata.sh
swift build
swift run LitePasteCoreChecks
git diff --check
```

If you build a local DMG for manual testing, verify the package layout:

```bash
Scripts/package_release.sh
Scripts/verify_dmg_contents.sh
```

## Notes

- Lite Paste stores clipboard history locally in `~/Library/Application Support/LitePaste/`.
- Accessibility permission is only needed for automatic paste. Copying selected history back to the clipboard works without it.
- iCloud backup is explicit and user-triggered. It is not real-time sync.
