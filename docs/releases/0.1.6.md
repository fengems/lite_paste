# Lite Paste 0.1.6

Lite Paste 0.1.6 fixes the panel not resetting scroll to the top when reopened, and restructures the data and UI layers into smaller modules.

## Highlights

- Opening the clipboard panel now reliably scrolls back to the first record instead of keeping a stale scroll position from the previous session.
- Data models renamed for clarity: `ClipboardItem` → `ClipboardRecord`, `ClipboardContent` → `ClipboardContentSnapshot`, with new fields for plain text, OCR text, content snapshots, and preview file paths.
- Persistence is isolated behind a repository layer, and settings are stored as a JSON configuration model.
- Large source files are split into focused modules (panel views, settings pages, pasteboard readers, panel placement, keyboard bridge, etc.).

## Build

Build the normal local app:

```bash
Scripts/build_app_bundle.sh --open
```

Build the isolated development-channel app:

```bash
LITEPASTE_FLAVOR=dev Scripts/build_app_bundle.sh --open
```

## Verification

Verify the source checkout and core behavior:

```bash
Scripts/verify_metadata.sh
swift build
swift run LitePasteCoreChecks
git diff --check
```

Verify the local release package:

```bash
Scripts/verify_release.sh
```

## Notes

- This release remains source-first for public distribution because the project does not currently have Apple Developer Program credentials for Developer ID signing and Apple notarization.
- Local release packages are still generated and verified for personal use.
