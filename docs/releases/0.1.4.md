# Lite Paste 0.1.4

Lite Paste 0.1.4 focuses on menu bar behavior, clipboard panel polish, settings coverage, and safer clipboard text extraction.

## Highlights

- Changed the menu bar icon click behavior to open the menu first, while keeping the panel available from the menu and global shortcut.
- Added a settings shortcut in the clipboard panel toolbar.
- Replaced the custom menu bar icon drawing with the same clipboard symbol used in Settings, then tuned its size and weight for the menu bar.
- Added interface language options and expanded Settings coverage for clipboard behavior, app behavior, appearance, OCR, and quick actions.
- Improved card and list selection styling, quick actions, keyboard navigation, and right-click action access.
- Replaced app-ignore and privacy-type ignore behavior with a simpler pause-monitoring model.
- Improved image OCR reuse so recognized text can support search and text copy or paste actions.

## Build

Build the normal local app:

```bash
Scripts/build_app_bundle.sh --open
```

Build the isolated development-channel app:

```bash
LITEPASTE_FLAVOR=dev Scripts/build_app_bundle.sh --open
```

## Verification

Verify the source checkout and core behavior:

```bash
Scripts/verify_metadata.sh
swift build
swift run LitePasteCoreChecks
git diff --check
```

Verify the local release package:

```bash
Scripts/verify_release.sh
```

## Notes

- This release remains source-first for public distribution because the project does not currently have Apple Developer Program credentials for Developer ID signing and Apple notarization.
- Local release packages are still generated and verified for personal use.
